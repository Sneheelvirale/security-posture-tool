2. Evidence Verification Register

To avoid self-reporting bias, controls require supporting evidence references:

None Provided
Level 0 Verification

No documentation, logs, or policies supplied. Score capped at 1.

Partially Verified
Level 1-2 Verification

Draft policies, verbal confirmation, or partial log samples provided.

Fully Verified
Level 3-5 Verification

Approved policies, audit logs, tool configurations verified by assessor.

3. Formula & Aggregation
Function Score Formula
Function Score = ( Sum of Control Scores in Function ) / ( Total Controls in Function )
Overall Posture Score Formula
Overall Score = ( Sum of all 5 Function Scores ) / 5.0

Equal weighting is applied across all five NIST CSF functions (Identify, Protect, Detect, Respond, Recover) ensuring balanced security coverage rather than over-focusing solely on technical protection controls.
